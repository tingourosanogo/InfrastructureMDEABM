## 2- Setting Git Bash as the Default
If you want Git Bash to open every time you start a new terminal:
 - Open the **Command Palette** by pressing **Ctrl + Shift + P**.
 - Type and select **"Terminal: Select Default Profile"**.
 - Select **Git Bash** from the options.

  To kill bash session : Ctrl + Z 
  To clean bash session : Ctrl + L
