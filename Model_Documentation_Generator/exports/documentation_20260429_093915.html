Introduction

Principe et définitions

Toute modélisation part d'une question de la forme :

Quel est l'impact de X sur Y étant donné Z ?

dans laquelle :

  • X définit l’ensemble des scénarios que l’on souhaite explorer

  • Y l’ensemble des indicateurs que l’on souhaite observer comme réponse aux différents scénarios

  • Z le contexte de la question

Concepts fondamentaux

  • Système : Système structuré en entités et processus

Types d'attributs :

  • parametres : dont la valeur ne varie pas au fil de la simulation

  • variables_etat : dont la simulation fait varier la valeur au fil du temps

Portée des attributs :

  • globaux : partagés par tout le système (nous avons choisi de les décrire dans l’entité « système »)

  • locaux : partagés par entités de même type

  • individuels : spécifiques à chaque entité

Relations questions-modèle

Formalisation :

X ⊆ A, Z ⊆ A, X ∩ Z = ∅, X ∪ Z = A

X est un sous-ensemble des attributs (de A)

Z est un sous-ensemble des attributs disjoint de X

X union Z = A

Y est calculé à partir des attributs

Implication : Un choix différent de X et Z permet de répondre à d'autres questions avec le même modèle On peut donc imaginer l’ensemble des questions auxquelles un même modèle peut répondre.

Pseudo-code tel que fourni par le modèle.

// Step 1: calculate Environmental Rate Factor (k) based on temp, moisture, pH, c/n ratio
// Temperature effect  
soil_temp = soil_temperature /* resource_063 */;
temp_factor = exp(0.069 * (soil_temp - 10)); 
if (temp_factor < 0) {
  temp_factor = 0;
}

// Moisture effect 
soil_moisture = soil_moisture /* resource_053 */; 
field_capacity_tmp = field_capacity /* resource_005 */;
moisture_factor = (soil_moisture / field_capacity_tmp);
if (moisture_factor > 1) {
  moisture_factor = 1;
}
if (moisture_factor < 0.2) {
  moisture_factor = 0;
}

// pH effect
soil_pH_tmp = soil_pH /* resource_052 */;
ph_factor = min(1, max(0, (soil_pH_tmp - 4)/(7 - 4))); 

// c/n ratio effect
cn_ratio_tmp = cn_ratio /* property_032 */;
cn_factor = min(1, max(0, (25 - cn_ratio_tmp)/15)); 

// calculate mineralization rate
k_base = base_mineralization_rate_k_base /* property_033 */;
k = k_base * temp_factor * moisture_factor * ph_factor * cn_factor;

// Step 2: Determine actual mass to mineralize (Robustness check)
rate = k * time_step; // k is the proportion of stock mineralized

// consumable organic stocks (current values)
litter_leaf_stock = leaf_litter /* resource_006 */;
litter_natural_stock = litter_natural /* resource_007 */;
litter_cultivated_stock = litter_cultivated /* resource_008 */;
manure_stock = manure /* resource_031 */;

// calculate consumed mass for each stock, capped at current stock availability
consumed_leaf = min(litter_leaf_stock * rate, litter_leaf_stock);
consumed_natural = min(litter_natural_stock * rate, litter_natural_stock);
consumed_cultivated = min(litter_cultivated_stock * rate, litter_cultivated_stock);
consumed_manure = min(manure_stock * rate, manure_stock);

// Step 3: calculate Mineralized n and c
n_from_leaf = consumed_leaf * leaf_litter_to_n /* property_046 */;
n_from_natural = consumed_natural * natural_litter_to_n /* property_002 */;
n_from_cultivated = consumed_cultivated * cultivated_litter_to_n /* property_083 */;
n_from_manure = consumed_manure * manure_to_n /* property_085 */;
n_mineralized = n_from_leaf + n_from_natural + n_from_cultivated + n_from_manure; // Total Mineralized nitrogen

c_from_leaf = consumed_leaf * leaf_litter_to_c /* property_004 */;
c_from_natural = consumed_natural * natural_litter_to_c /* property_001 */;
c_from_cultivated = consumed_cultivated * cultivated_litter_to_c /* property_003 */;
c_from_manure = consumed_manure * manure_to_c /* property_084 */;
c_mineralized = c_from_leaf + c_from_natural + c_from_cultivated + c_from_manure; // Total Mineralized carbon 

// Step 4: Update Resources (Mineral Pools increase, Organic Stocks decrease)
soil_nitrogen /* resource_001 */ = soil_nitrogen + n_mineralized; 
soil_carbon /* resource_002 */ = soil_carbon + c_mineralized; 

leaf_litter /* resource_006 */ = leaf_litter - consumed_leaf; 
natural_litter /* resource_007 */ = natural_litter - consumed_natural; 
cultivated_litter /* resource_008 */ = cultivated_litter - consumed_cultivated;
manure /* resource_031 */ = manure - consumed_manure;

Pseudo-code

Pseudo-code tel que fourni par le modèle.

// 1. Get Biomass and Rates
biomass_stock = Biomass /* resource_027 */;
base_litter_rate = litter_fall_rate /* property_054 */;
drought_mortality_rate = drought_mortality_rate /* property_036 */;

// 2. Get Environmental Condition for Stress Calculation
soil_moisture = soil_moisture /* resource_053 */; 
field_capacity = field_capacity /* resource_005 */;

// Calculate Drought Stress Factor: Scales from 0 (low stress) to 1 (max stress)
// We use max(0, 1 - ...) to prevent negative stress values if moisture exceeds field capacity
drought_stress_factor = max(0, 1 - (soil_moisture / field_capacity));

// Calculate Total Fall Rate: Base rate + stress-induced rate
total_fall_rate = base_litter_rate + (drought_mortality_rate * drought_stress_factor);

// 3. Calculate actual litter fall amount (Robustness Check)
litter_fall_amount_potential = biomass_stock * total_fall_rate;

// The amount consumed cannot exceed the current stock
litter_fall_amount = min(litter_fall_amount_potential, biomass_stock);

// Split litter fall between two natural pools (e.g., 50/50 split)
litter_to_leaf = litter_fall_amount * 0.5;
litter_to_natural = litter_fall_amount * 0.5;

// 4. Update Resources (Mass Balance)
biomass /* resource_027 */ = biomass - litter_fall_amount; 

leaf_litter /* resource_006 */ = leaf_litter + litter_to_leaf;
natural_litter /* resource_007 */ = natural_litter + litter_to_natural;

Pseudo-code

Pseudo-code tel que fourni par le modèle.

// 1. Get Environmental Limiting Factors
optimal_rainfall = optimal_rainfall /* property_031 */;
rainfall = rainfall /* resource_010 */;
rain_factor = min(1, rainfall / optimal_rainfall); 

soil_nitrogen_current = soil_nitrogen /* resource_001 */;

// 2. Calculate Grazing Pressure (Stress Factor)
fodder_consumption_rate = fodder_consumption_rate /* property_060 */;

                sub_adult_male_count + sub_adult_female_count + 
                adult_male_count + adult_female_count) * fodder_consumption_rate;

max_grazing_capacity = max_grazing_capacity /* #property_073 */;
seasonal_fodder_current = seasonal_fodder /* resource_041 */;

if (seasonal_fodder_current > 0) {
  // Calculate pressure ratio. Denominator is capped at max(1, ...) to prevent division by zero
  grazing_pressure = min(1.0, total_demand / max(1, seasonal_fodder_current * max_grazing_capacity)); 
} else {
  // Maximum pressure (1.0) when no fodder is available
  grazing_pressure = 1.0; 
}

fodder_quality = fodder_quality /* property_053 */;

growth = r_max * rain_factor * n_factor * stress * fodder_quality;

seasonal_fodder = seasonal_fodder + growth;

// Nitrogen Uptake (Robustness: Ensure Soil_Nitrogen does not go below zero)

Comportement

Description détaillée du processus (équations, états, activités, etc.).

Équation :

ResidueConsumed = ResidueStock * (GrazingProp + IncorpProp) Feed = Residue * GrazingProp Litter = Residue * IncorpProp

Pseudo-code

Pseudo-code tel que fourni par le modèle.

// Total residue available
residue_stock = crop_residue /* resource_035 */;

// Get Proportions
grazing_prop = residue_grazing_prop /* property_124 */;
incorporation_prop = residue_incorp_prop /* property_125 */;

// 1. Conditional Execution and Proportion Scaling (Robustness Check)
if (residue_stock > 0) {
  // Calculate total requested consumption proportion
  total_management_prop = grazing_prop + incorporation_prop;

  if (total_management_prop > 1.0) {
    // Scale proportions down so their sum equals 1.0, consuming all residue
    grazing_prop_actual = grazing_prop / total_management_prop;
    incorporation_prop_actual = incorporation_prop / total_management_prop;
  } else {
    // Use original proportions (leaving unallocated residue in stock)
    grazing_prop_actual = grazing_prop;
    incorporation_prop_actual = incorporation_prop;
  }

  // 2. Calculate final allocations
  residue_to_feed = residue_stock * grazing_prop_actual;
  residue_to_litter = residue_stock * incorporation_prop_actual;

  // Total mass consumed from stock
  total_residue_consumed = residue_to_feed + residue_to_litter; 

  // 3. Update Resources (Mass Balance)
  // Consume the stock (resource_035)

              + young_female_count /* resource_021 */ 
              + sub_adult_male_count /* resource_022 */ 
              + sub_adult_female_count /* resource_023 */

  default_body_weight = body_weight_default /* property_052 */;

  fodder_consumption_rate = fodder_consumption_rate /* property_060 */;

  // Adjust requirement based on other needs (Metabolic, Mobility, Lactation)
  metabolic_need = metabolic_need /* property_019 */;
  mobility_need = mobility_need /* property_020 */;
  lactation_need = lactation_need /* property_063 */;

  // Total required fodder (DM) including needs adjustments
  required_fodder_dm = herd_biomass * fodder_consumption_rate;
  required_fodder_dm = required_fodder_dm * (1 + metabolic_need + mobility_need + lactation_need);

  // 2. Hierarchical Consumption (Private Stock Priority)

  // Available Private Stocks (The stock that is consumed FIRST)
  hay_stock = hay /* resource_032 */;
  residue_stock = crop_residue_to_feed /* resource_033 */;
  concentrate_stock = concentrate /* resource_034 */;

  // Total usable private stock for feeding (assuming 80% usable fraction for concentrate)
  total_private_stock = hay_stock + residue_stock + (concentrate_stock * 0.8);

  // Amount covered by private stock
  consumed_from_private = min(required_fodder_dm, total_private_stock);

  // Remaining deficit must be covered by external Seasonal Fodder (rangelands)
  deficit_to_be_covered = required_fodder_dm - consumed_from_private;

  // 3. External Fodder Reliance and Actual Intake

  quality_factor = max(0.0, min(1.0, fodder_quality /* property_053 */)); 
  intake_mod_factor = max(0.0, intake_factor /* property_051 */);

  adjusted_seasonal_fodder = seasonal_fodder_stock * quality_factor * (1 + intake_mod_factor);

  // Actual mass consumed from seasonal fodder (cannot exceed stock or adjusted capacity)
  consumed_from_seasonal = min(deficit_to_be_covered, adjusted_seasonal_fodder);

  actual_intake_dm = consumed_from_private + consumed_from_seasonal;

  if (total_private_stock > 1e-6) {
    consumption_ratio_private = consumed_from_private / total_private_stock;

    concentrate /* resource_034 */ = concentrate - (concentrate_stock * 0.8) * consumption_ratio_private / 0.8;
  }

  // B. Consume Seasonal Fodder
  seasonal_fodder /* resource_041 */ = seasonal_fodder - consumed_from_seasonal; 

  // C. Migration Pressure Output (The link to process_009)
  // Ratio of total requirement that HAD to be sourced from external seasonal fodder
  seasonal_fodder_reliance = min(1.0, deficit_to_be_covered / max(required_fodder_dm, 1e-6)); 
  seasonal_fodder_reliance /* resource_073 */ = seasonal_fodder_reliance;

  nutrients_consumed /* resource_051 */ = nutrients_consumed_mass;

  daily_intake_ratio /* resource_075 */ = actual_intake_dm / max(required_fodder_dm, 1e-6);

  nutrients_consumed /* resource_051 */ = 0; 
  seasonal_fodder_reliance /* resource_073 */ = 0;
